# AI Career Recommendation System

An intelligent career recommendation system that helps students find suitable technology careers based on their skills.

## Features

- Skill assessment
- Career recommendation
- Match percentage
- Skill gap analysis
- Personalized learning roadmap
- Responsive web interface

## Technology Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- CSV
- GitHub

## How It Works

The user enters their skill levels from 0 to 100.

The system compares the skills with different career requirements and recommends the top matching careers.

## Careers Covered

- Data Analyst
- Data Scientist
- Software Engineer
- Machine Learning Engineer
- Web Developer
- Business Analyst
